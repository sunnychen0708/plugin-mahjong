MahjongPlay-TW 3D 3.1.0 source

src/            Plugin and Taiwanese Mahjong engine source
resources/      plugin.yml
tests/          Engine self-test
test-stubs/     Minimal local Paper/Bukkit API stubs used only for compile/smoke testing

The test stubs are not a replacement for the real Paper API and must not be bundled in the plugin JAR.
Build the plugin against the Paper 26.2 API and package compiled classes together with resources/plugin.yml and NOTICE.txt.
